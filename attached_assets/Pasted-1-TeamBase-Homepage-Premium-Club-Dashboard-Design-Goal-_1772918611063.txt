Key Design Decisions
XP Badge

Top right.

[150]

Color = tier color

Click → /profile#xp

XP stays visible but subtle.

Club Identity

Top section uses:

• club crest
• club primary color accent
• club banner if available

Example:

background: club primary tint
Split Grid Layout

Instead of stacking everything vertically:

Club Momentum | Activity Feed

This cuts scrolling by 40–50%.

Quick Log Strip

Horizontal actions.

Run | Gym | SAQ | Recovery | Social

Tap → quick check-in modal.

Interaction Details
Check-in Button

Uses club primary color.

Hover/active:

background → club accent
Momentum Bar

Animated slightly when club points increase.

Example:

+15 club points

Bar grows.

Visual System
Base palette
Background: warm light grey
Typography: dark slate
Accent: club color
Gold: premium highlight
Radius
Cards: 8px
Buttons: 8px
Badge: pill

Avoid large 20px soft radius.

Club Branding Behaviour

Every club can configure:

logo
banner
primary color
secondary color
accent color

Those automatically theme:

• hero section
• buttons
• progress bars
• nav highlights

Example
Sharks RFC
primary: navy
secondary: gold
accent: bright gold
Stone Town RFC
primary: red
secondary: white
accent: dark red
Result

The entire app subtly shifts based on the user’s club.

Players feel like they’re in:

Sharks RFC App

not:

Generic Rugby System
