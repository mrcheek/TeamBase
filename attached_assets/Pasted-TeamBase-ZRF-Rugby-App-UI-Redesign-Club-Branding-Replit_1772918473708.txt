TeamBase / ZRF Rugby App
UI Redesign + Club Branding
Replit Implementation Plan (V2)
Objective

Transform the ZRF Rugby App from an XP-centric utility interface into a premium club-first sports platform.

Each member should feel like they are entering:

their club’s digital home

Key outcomes:

• Club identity dominates the experience
• Each club can define its own branding
• UI dynamically adapts to club theme
• XP and tiers remain visible but subtle
• Homepage emphasizes club momentum and participation
• Platform remains scalable to multi-sport / multi-federation

Implementation Architecture

The redesign introduces four main systems:

1️⃣ Club Branding Data Model
2️⃣ Dynamic Club Theme Engine
3️⃣ Premium Design System
4️⃣ UI Refactor Across All Screens

Field	Purpose

accentColor	optional highlight
textOnPrimary	contrast text color
textOnSecondary	contrast text
brandStyle	visual style preset

PHASE 2 — Club Branding Assets
T002 — Club Logo & Banner Upload System

Blocked by: T001

Allow clubs to upload assets.

Supported uploads:

• club crest/logo
• optional banner/hero image

Validation:

• PNG / SVG / JPG
• max size 2MB
• recommended aspect ratios

Logo:

1:1 square

Banner:

16:9 landscape
Backend

Create upload endpoints:

POST /api/clubs/:id/logo
POST /api/clubs/:id/banner

Store:

logoUrl
bannerUrl
Fallback

If no logo:

Generate club initials.

Example:

Sharks RFC → SR
Files
server/routes.ts
client/components/logo-upload.tsx
client/components/banner-upload.tsx
Acceptance

• Club admins can upload logo
• Logo appears in UI immediately
• Banner available for hero sections

PHASE 3 — Dynamic Club Theme Engine
T003 — Club Theme Context

Blocked by: T001

Create:

client/src/hooks/use-club-theme.tsx

This provider:

1️⃣ fetches user's active club
2️⃣ applies club branding globally
3️⃣ exposes theme values to components

CSS Variables

Set at root:

--club-primary
--club-secondary
--club-accent

--club-primary-foreground
--club-secondary-foreground

--club-surface
--club-surface-strong
--club-border
Example

For Sharks RFC:

--club-primary: #0A2342
--club-secondary: #C8A951
--club-accent: #FFD700
Tailwind Integration

Update:

tailwind.config.ts

Add:

colors: {
clubPrimary: "var(--club-primary)",
clubSecondary: "var(--club-secondary)",
clubAccent: "var(--club-accent)"
}
Acceptance

• UI dynamically adopts club colors
• fallback federation theme works
• multi-club users supported
