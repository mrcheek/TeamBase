The Rule: The Homepage Has Only 5 Blocks

No matter how many features you add, the homepage should never exceed five sections.

Your final structure should be:

1. Club Hero
2. Next Session
3. Today’s Challenge
4. Club Activity
5. Quick Log

Everything else lives elsewhere.

For example:

Feature	Where it goes
Club leaderboard	Play page
Events list	Play page
XP details	Profile
Admin tools	Admin
Club roster	Club page

This keeps the homepage light and alive.

Why This Works

It answers the three things users care about immediately:

1️⃣ What’s happening next?
→ Next Session

2️⃣ What should I do today?
→ Daily Challenge

3️⃣ What are my teammates doing?
→ Activity Feed

Everything else is secondary.

One More Important Rule

Never add a sixth homepage section.

If you ever want to add something new, ask:

Which of the five blocks does this belong to?

If it doesn’t belong to one, it goes on another page.
