ZRF RUGBY APP
Full MVP Specification (With Future Rails)
1. Product Principles

The ZRF app is designed to become the digital infrastructure of rugby in Zanzibar.

The system must support:

Players

Clubs

Federation administrators

Supporters

SMS-only members

Core goals:

Track who plays rugby

Track where rugby happens

Track who participates

Support player development

Strengthen club culture

Support rugby growth

The app must be:

Mobile-first (PWA)

Low bandwidth friendly

Accessible to non-smartphone users (SMS/USSD)

Bilingual (English / Swahili)

2. System Architecture

The platform is designed with a multi-federation structure to allow future expansion.

Example structure:

Platform
   └ Federation
        └ Clubs
             └ Members
                  └ Events

Example:

Platform
 ├ Zanzibar Rugby Federation
 │   ├ Sharks RFC
 │   ├ Stone Town RFC
 │   └ Pemba RFC
 │
 ├ Tanzania Rugby Union
 ├ Kenya Rugby Union
 └ Uganda Rugby Union

For MVP only Zanzibar Rugby Federation is active.

All system objects include:

federation_id
3. Core MVP Features (10)

These features must exist at launch.

1. User Accounts & Rugby Profiles

Each user has a rugby identity.

Required fields:

full name

phone number

portrait photo (mandatory)

role (player / coach / supporter / admin)

club membership

preferred language

Rule:

Portrait photo required to activate membership

Photos appear in:

profiles

membership cards

attendance lists

activity feed

2. Registration Workflow (Myself / A Friend)

The system supports self-registration and proxy registration.

Register Myself

Standard sign-up.

Register A Friend

Used when a player:

has no smartphone

needs help registering

is being registered by a coach/admin

Fields collected:

name

phone number

club

role

portrait photo

Status:

Pending → Club admin approval → Active

The friend can later claim their profile using phone verification.

3. SMS-Only Members

Members without smartphones can still participate.

SMS members can:

be registered

appear in club rosters

be checked in by admins

receive SMS updates

SMS notifications include:

training reminders

event updates

match notifications

federation announcements

4. Club Directory & Membership

Users can browse clubs.

Club pages include:

club logo

location

description

training schedule

club administrators

member list

Membership flow:

Apply → Admin approval → Membership active
5. Events & Rugby Calendar

Clubs can create events.

Event types:

training

touch rugby

match

tournament

social event

Event page includes:

date

time

location

club

attendee list

Events support:

QR check-in

admin roster check-in

6. Ultra-Simple Check-In (Central Button)

Check-in is the primary action in the app.

Bottom navigation:

Home | Play | ⬤ Check-In | Train | Profile

Check-in options:

Scan Event QR

Quick Activity

Selfie Check-in

Goal:

Check-in in under 5 seconds
7. Activity Tracking

Members can log rugby-related activities.

Examples:

SAQ training

gym

running

recovery

watching rugby

team social

Rules:

1 check-in per activity per day

Selfie posts can provide bonus XP.

8. XP System & Membership Tiers

Participation earns XP.

Example tier system:

Tier	Colour
Green	starter
Royal Blue	active
Silver	elite
Gold	ambassador

XP contributes to:

player progression

club score

leaderboards

9. Digital Membership Card

Every member receives a digital rugby membership card.

Card includes:

portrait photo

member name

club

tier colour

QR code

Uses:

event entry

attendance verification

future partner discounts

10. Club Score System

Clubs accumulate points through member activity and development.

Formula:

Club Score =
50% of member XP
+ club contributions

Club contributions include:

hosting events

registering players

certifying coaches

qualifying referees

Example leaderboard:

ZRF Club Rankings
