What Still Feels Slightly Heavy

There are three remaining surfaces that still feel too “panel-like”.

1. Next Session card

Right now it's still a full card. It doesn't need the border.

Better structure:

NEXT SESSION

Touch Rugby Afternoon
Sat 7 Mar • 15:00
Forodhani Gardens

Check In     Details

Use background tint only (very subtle club colour), not a border.

2. Quick Log buttons

The square buttons are fine functionally but visually a bit chunky.

Better version:

Run   Gym   SAQ   Recovery   Social

Use circular icons + labels underneath instead of square containers.

Example:

[👟]
Run

[🏋]
Gym

This instantly feels more “sports”.

3. Club Table

Right now the list is good but slightly boxed.

Make it feel more like a league table.

Example:

ZRF CLUB TABLE

1  Jambiani Jackals RFC      1197
2  Stone Town Sultans RFC     177
3  Paje Pirates RFC            75

With thin dividers only.

The rank circle icons are good — keep those.

The One Element That Still Feels Off
The Hero Color

The bright blue gradient feels generic tech app, not club identity.

Eventually this should become club colour driven.

Example:

Sharks RFC → navy / gold
Stone Town → red
Paje Pirates → orange

For now, even reducing saturation slightly will make it feel more premium.

Spacing Improvements

You can improve visual calm by slightly increasing vertical rhythm.

Current spacing feels around:

16px

Better spacing system:

Hero → 32px
Section → 28px
Subsections → 20px

More breathing room = more premium.
